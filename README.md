# Парсер облигаций - Московская Биржа (MOEX)

Автоматический парсер для сбора и обновления данных об облигациях с сайта Московской Биржи (https://www.moex.com/) с последующей записью в Google Sheets каждые 10 минут.

## Функциональность

- ✅ Автоматический сбор данных об облигациях с MOEX
- ✅ Периодическое обновление каждые 10 минут
- ✅ Запись данных в Google Sheets
- ✅ Сбор всех обязательных полей:
  - Котировка (SECID)
  - Название облигации (SECNAME)
  - Дата погашения (MATDATE)
  - Дата выплаты купона (NEXTCOUPON)
  - Сумма купона (COUPONVALUE)
  - НКД - накопленный купонный доход (ACCRUEDINT)
  - Периодичность выплаты купонов (COUPONPERIOD, рассчитывается автоматически)
  - Номинал облигации (FACEVALUE)
  - Статус/Рейтинг (STATUS)
  - Дата оферты (OFFERDATE)
  - **Текущая стоимость (LAST/PRICE)** - добавлено новое поле
  - Время последнего обновления

## Установка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd mos
```

### 2. Создание виртуального окружения

```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# Linux/Mac
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка Google Sheets API

#### Шаг 1: Создание проекта в Google Cloud Console

1. Перейдите на https://console.cloud.google.com/
2. Создайте новый проект
3. Назовите его (например, "MOEX Bonds Parser")

#### Шаг 2: Включение Google Sheets API

1. В поиске найдите "Google Sheets API"
2. Нажмите "Включить"
3. Повторите для "Google Drive API"

#### Шаг 3: Создание Service Account

1. Перейдите в "Учетные данные" (Credentials)
2. Создайте новый сервисный аккаунт
3. Дайте ему имя (например, "bonds-parser")
4. Перейдите в созданный аккаунт
5. На вкладке "Ключи" создайте новый ключ JSON
6. Скачайте файл и переименуйте его в `credentials.json`
7. Поместите файл в корневую папку проекта

#### Шаг 4: Создание Google Sheets и предоставление доступа

1. Создайте новую Google Таблицу на https://docs.google.com/spreadsheets/
2. Поделитесь ею с email адресом сервисного аккаунта (найдите в credentials.json поле "client_email")
3. Скопируйте ID таблицы из URL:
   ```
   https://docs.google.com/spreadsheets/d/{GOOGLE_SHEET_ID}/edit
   ```

### 5. Конфигурация приложения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Отредактируйте `.env` и заполните необходимые переменные:

```env
# Google Sheets конфигурация
GOOGLE_SHEET_ID=ваш_id_таблицы_здесь
GOOGLE_CREDENTIALS_FILE=credentials.json

# MOEX конфигурация
MOEX_URL=https://www.moex.com/

# Интервал обновления в секундах (600 = 10 минут)
UPDATE_INTERVAL=600

# Логирование
LOG_LEVEL=INFO
LOG_FILE=bonds_parser.log
```

## Запуск приложения

```bash
python main.py
```

При первом запуске:
- Программа создаст лист "Облигации" в Google Sheets
- Запишет заголовки столбцов
- Выполнит первоначальную загрузку данных
- Начнет периодические обновления каждые 10 минут

## Логирование

Логи записываются в:
- **Консоль** - для оперативной информации
- **bonds_parser.log** - для архива событий

## Переменные окружения

| Переменная | Описание | По умолчанию |
|-----------|---------|------------|
| `GOOGLE_SHEET_ID` | ID Google таблицы | - (обязательно) |
| `GOOGLE_CREDENTIALS_FILE` | Путь к credentials.json | credentials.json |

## Решение проблем

### Ошибка: "GOOGLE_SHEET_ID не установлен"

Убедитесь, что:
1. Создан файл `.env`
2. В `.env` указан GOOGLE_SHEET_ID
3. ID скопирован правильно из URL таблицы

### Ошибка: "Не удалось аутентифицироваться в Google Sheets"

Убедитесь, что:
1. Файл `credentials.json` находится в папке проекта
2. Сервисный аккаунт имеет доступ к таблице Google Sheets
3. Google Sheets API включена в Cloud Console

### Не получены данные об облигациях

1. Проверьте интернет соединение
2. Проверьте логи в `bonds_parser.log`
3. Убедитесь, что MOEX сайт доступен

## Архитектура

### MOEXBondsParser (`parser.py`)
Класс для работы с данными MOEX:
- Получение данных через MOEX ISS API
- Парсирование JSON ответа
- Извлечение необходимых полей

### GoogleSheetsHandler (`sheets_handler.py`)
Класс для работы с Google Sheets:
- Аутентификация через Service Account
- Создание и управление листами
- Чтение/запись данных
- Преобразование данных в формат таблицы

### BondsUpdater (`main.py`)
Главный класс для управления процессом:
- Инициализация компонентов
- Планирование периодических обновлений
- Управление жизненным циклом приложения

## Структура данных в Google Sheets

Таблица содержит следующие столбцы:

| Столбец | Описание | Пример |
|---------|---------|--------|
| Котировка | Код облигации на бирже | POSI |
| Название | Полное название облигации | ПТБ 2028 |
| Дата погашения | Дата, когда облигация истекает | 21.04.2028 |
| Дата выплаты купона | Дата следующей выплаты купона | 21.04.2024 |
| Сумма купона | Размер купона в %/года | 9.40 |
| НКД | Накопленный купонный доход | 1.23 |
| Периодичность выплаты | Как часто выплачивается купон | Полугодие |
| Номинал | Номинальная стоимость облигации | 1000 |
| Статус (Рейтинг) | Статус и рейтинг облигации | ААА |
| Дата оферты | Дата оферты (если есть) | 01.01.2024 |
| Последнее обновление | Время последнего обновления данных | 2024-01-15T10:30:45 |

## Примечания

- Парсер работает с открытыми данными MOEX ISS API
- Обновление данных не требует авторизации на сайте MOEX
- Рекомендуется установить интервал обновления не менее 5 минут
- При необходимости можно запустить несколько экземпляров с разными таблицами
