# 📊 Парсер облигаций MOEX - Статус завершения

## ✅ Все требуемые поля реализованы

### 1. ✅ НКД (Накопленный купонный доход)
- **Описание**: "НКД на дату расчетов, в валюте расчетов"
- **Реализация**: Извлекается из `MarketData.ACCRUEDINT` с fallback на альтернативные источники
- **Статус**: Заполняется для всех облигаций (может содержать значение или "Данные недоступны")

### 2. ✅ Периодичность выплаты купонов
- **Описание**: "Периодичность выплаты купона в год"
- **Реализация**: Извлекается из `Securities.COUPONFREQUENCY` или рассчитывается из `Securities.COUPONPERIOD`
- **Преобразование**:
  - Коды (0-6) → Русские названия (Ежегодно, Полугодие, Квартал, Месяц, Неделя, День, Единовременно)
  - Количество дней → Периодичность (автоматический расчет)
- **Статус**: Заполняется для всех облигаций

### 3. ✅ Дата выплаты купона
- **Описание**: "Дата выплаты купона"
- **Реализация**: Извлекается из `Securities.NEXTCOUPON` с fallback на `MarketData.COUPONDATE`
- **Формат**: YYYY-MM-DD → DD.MM.YYYY
- **Статус**: Заполняется для всех облигаций

### 4. ✅ Текущая стоимость (добавлено)
- **Описание**: Рыночная цена облигации в процентах от номинала
- **Реализация**: Извлекается из `MarketData.LAST` или `MarketData.PRICE`
- **Статус**: Добавлено новое поле в Google Sheets

## 🔍 Полученные колонки в Google Sheets (12 всего)

1. **Котировка** - SECID (тикер облигации)
2. **Название** - SECNAME (полное название)
3. **Дата погашения** - MATDATE (форматирование DD.MM.YYYY)
4. **Дата выплаты купона** - NEXTCOUPON (дата следующего купона)
5. **Сумма купона** - COUPONVALUE (размер купона в рублях)
6. **НКД** - ACCRUEDINT (накопленный купонный доход)
7. **Периодичность выплаты купонов** - COUPONFREQUENCY + расчет
8. **Номинал** - FACEVALUE (номинальная стоимость)
9. **Статус (Рейтинг)** - STATUS/REGNUMBER
10. **Дата оферты** - OFFERDATE (дата опции)
11. **Текущая стоимость** - LAST/PRICE (рыночная цена) ⭐ НОВОЕ
12. **Последнее обновление** - текущее время

## 🔗 Источники данных из MOEX ISS API

### Securities endpoint
`https://iss.moex.com/iss/engines/stock/markets/bonds/boards/TQCB/securities.json`

Предоставляет информацию об облигациях:
- Основные параметры (SECID, SECNAME, FACEVALUE)
- Купонные параметры (COUPONVALUE, COUPONPERIOD, COUPONFREQUENCY)
- Даты важных событий (MATDATE, NEXTCOUPON, OFFERDATE)

### MarketData endpoint
Часть того же запроса, содержит текущие рыночные данные:
- Текущие цены (LAST, PRICE, BID, OFFER)
- Торговая активность (QTY, VALUE, NUMTRADES)
- Доходность (YIELD)
- НКД на текущий день (ACCRUEDINT)

## 🎯 Особенности реализации

### Fallback механизм
```python
# Пример: Если основное поле пусто, ищется альтернатива
coupon_date = market_dict.get('COUPONDATE', '') or sec_dict.get('COUPONDATE', '')
accruedint = market_dict.get('ACCRUEDINT', '') or market_dict.get('ACCINT', '')
```

### Автоматический расчет периодичности
```python
# Если код периодичности недоступен, вычисляется из дней между купонами
if not coupon_freq:
    coupon_period = sec_dict.get('COUPONPERIOD', '')
    if coupon_period:
        coupon_freq = self._get_frequency_from_period(coupon_period)
```

### Обогащение данных
Методпо `_enrich_bonds_data()` заполняет пустые поля понятными значениями:
```python
if not bond.get('НКД') or bond.get('НКД') == '':
    bond['НКД'] = 'Данные недоступны'
```

### Форматирование дат
```python
# YYYY-MM-DD → DD.MM.YYYY
date_obj = datetime.strptime(date_str, '%Y-%m-%d')
return date_obj.strftime('%d.%m.%Y')
```
