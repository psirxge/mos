# Описание полей MOEX ISS API для облигаций

## Securities (Параметры облигаций)

Основной источник информации об облигациях:

| Поле | Русское название | Описание |
|------|-----------------|---------|
| SECID | Котировка | Уникальный идентификатор облигации (тикер) |
| SECNAME | Название | Полное название облигации |
| SHORTNAME | Краткое название | Краткое название облигации |
| MATDATE | Дата погашения | Дата погашения облигации в формате YYYY-MM-DD |
| FACEVALUE | Номинал | Номинальная стоимость облигации |
| COUPONVALUE | Сумма купона | Размер купона в рублях |
| COUPONPERIOD | Период купона | Количество дней между выплатами купонов |
| COUPONFREQUENCY | Периодичность купона | Код периодичности (0=год, 1=полугодие, 2=квартал, 3=месяц) |
| NEXTCOUPON | Дата выплаты купона | Дата следующей выплаты купона |
| ACCRUEDINT | НКД | Накопленный купонный доход на дату расчетов |
| OFFERDATE | Дата оферты | Дата дополнительной (оф) опции |
| STATUS | Статус | Статус облигации на бирже |
| REGNUMBER | Регистрационный номер | Номер из реестра ЦБ РФ |
| CURRENCYID | Валюта | Валюта облигации (обычно RUB) |
| ISSUESIZE | Объем выпуска | Общий размер выпуска облигаций |
| ISSUESIZEPLACED | Размещено | Размер размещенной части выпуска |

## MarketData (Рыночные данные)

Текущие рыночные котировки и показатели:

| Поле | Русское название | Описание |
|------|-----------------|---------|
| LAST | Последняя сделка | Цена последней сделки |
| PRICE | Цена | Текущая рыночная цена |
| BID | Спрос | Лучшая цена спроса |
| OFFER | Предложение | Лучшая цена предложения |
| OPEN | Открытие | Цена открытия дня |
| HIGH | Максимум | Максимальная цена дня |
| LOW | Минимум | Минимальная цена дня |
| YIELD | Доходность | Текущая доходность |
| YIELDATWAPRICE | Доходность по WAP | Доходность по средневзвешенной цене |
| ACCRUEDINT | НКД | Накопленный купонный доход (текущий день) |
| NUMTRADES | Кол-во сделок | Количество сделок за день |
| VOLTODAY | Объем торговли | Объем торговли за день в штуках |
| VALTODAY | Стоимость торговли | Стоимость торговли за день в рублях |
| UPDATETIME | Время обновления | Время последнего обновления данных |

## Как работает парсинг

### НКД (Накопленный купонный доход)
- **Источник**: MarketData.ACCRUEDINT или Securities.ACCINT
- **Описание**: "НКД на дату расчетов, в валюте расчетов"
- **Поиск**: Сначала проверяется ACCRUEDINT в marketdata, потом ACCINT в marketdata, потом ACCINT в securities
- **Статус**: Может быть недоступен для некоторых облигаций

### Периодичность выплаты купона
- **Источник**: Securities.COUPONPERIOD или Securities.COUPONFREQUENCY
- **Описание**: "Периодичность выплаты купона в год"
- **Поиск**: Сначала проверяется COUPONFREQUENCY, потом COUPONFREQ, потом рассчитывается из COUPONPERIOD
- **Расчет**: На основе количества дней между купонами:
  - <= 7 дней: Неделя
  - <= 31 день: Месяц
  - <= 92 дня: Квартал
  - <= 184 дня: Полугодие
  - > 184 дней: Ежегодно

### Дата выплаты купона
- **Источник**: Securities.NEXTCOUPON или MarketData.COUPONDATE
- **Описание**: "Дата выплаты купона"
- **Поиск**: Сначала проверяется COUPONDATE в marketdata, потом NEXTCOUPON в securities
- **Статус**: Всегда доступна как дата следующего купона

### Текущая стоимость (добавлено)
- **Источник**: MarketData.LAST или MarketData.PRICE
- **Описание**: "Текущая рыночная стоимость облигации в процентах от номинала"
- **Поиск**: Сначала проверяется LAST, потом PRICE

## Примечания

1. **Доступность данных**: Не все облигации имеют данные по всем полям. Некоторые поля могут быть пусты (например, НКД для некоторых типов облигаций)

2. **Частота обновления**: Рыночные данные обновляются в реальном времени, данные securities обновляются реже

3. **Формат данных**:
   - Даты приходят в формате YYYY-MM-DD и преобразуются в DD.MM.YYYY
   - Численные значения хранятся как числа или строки
   - Коды преобразуются в понятные названия

4. **Дополнительные источники**: Для получения более полной информации можно использовать:
   - `/iss/statistics/engines/stock/markets/bonds/monthendaccints` - НКД на конец месяца
   - `/iss/engines/stock/markets/bonds/boards/{board}/securities/{secid}` - информация по конкретной облигации
