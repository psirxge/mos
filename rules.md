Создай парсер облигаций на python. 

Скрипт должен постоянно работать, записывать и обновлять Google sheets информацией об облигациях с сайта Московской Биржи (https://www.moex.com/) каждые 10 минут.

Обязательные поля для заполнения:
    - Котировка
    - Название
    - Дата погашения
    - Дата выплаты купона
    - Сумма купона
    - НКД
    - Периодичность выплаты купонов
    - Номинал 
    - Статус(Рейтинг)
    - Дата оферты 


Записывай все переменные в файл .env и используй библиотеку python-dotenv для их загрузки. Необходимо чтобы при загрузке в git файл .env игнорировался.

Игнорировать сообщение ниже
Телеграм бот должен взаимодействовать с таблицей Google sheets и предоставлять пользователю возможность применить фильтры к таблице и получить информацию по облигациям
Бот должен отправить краткую сводку по заданным фильтрам и ссылку на moex "https://www.moex.com/ru/issue.aspx?code=КОТИРОВКА", где КОТИРОВКА - это котировка облигации.

К телеграм боту должен быть прикручен искуственный интеллект который будет анализировать фильтры пользователя и предлагать оптимальные варианты облигаций на основе фильтров. 
Ключевая оценка:
    - Высокая купоновая доходность
    - Близка дата погашения / оферты
